# Clawdy 界面与交互逻辑说明（v0.1 概念稿）

配色：暖奶油底 #FFFBF7 · 珊瑚橙 #E07F5F · 浅橙任务卡 #FDEBDD · 桃粉用户气泡 #F9E1D6；深色模式为暖棕黑 #1C1816。
头像状态：idle 待机 / working 工作中 / waiting 等待确认（冒汗）/ happy 完成 / error 出错。

---

## 01 首页（空状态）
- 顶栏：左边 ☰ 打开侧边栏（08），右边 ✎ 新建对话。
- 中间是 Clawdy 头像加问候语，问候语按时段切换（早上好/下午好/晚上好）；页面上没有建议按钮。
- 输入框上方一行显示工具连接状态：Termux · Hands 无障碍 · Linux 沙箱 · Shizuku。
  - 绿点表示已连接，灰色空心表示未连接；点任意一项进入「工具连接」（11）。
- 输入框：
  - 「+」打开附件面板（13）。
  - 模型胶囊打开模型选择（09）。
  - 🎤 语音输入。
  - 有内容时发送按钮变珊瑚色；空输入时发送按钮不可点。

## 02 对话 · 任务进行中（卡片收起）
- 用户发出任务后，助手头像切成 working，对话流里只出现一张浅橙色任务卡，默认收起。
- 卡片显示：
  - 转圈图标、「正在处理 · 第 n/N 步」。
  - 当前步骤的一句话描述和已用时间。
  - 底部进度条。
- 点卡片任意位置展开（03）。
- 任务进行时，发送按钮变成 ■ 停止。
  - 点停止先中断当前工具调用，再结束 Agent 循环；卡片标为「已停止」。
- 任务进行中还可以继续输入。新消息会排队，或在当前步骤结束后插入成补充指令。

## 03 对话 · 任务卡展开
- 卡片在原位展开成步骤时间线：已完成是绿色勾，进行中是珊瑚色转圈，未开始是灰色空心圈。
- 每步显示：工具图标（思考 / Termux / Hands / 沙箱 / 联网）、标题，以及耗时、exit 码之类的元信息。
  - Termux 步骤附一行命令预览。
- 点某一步打开步骤详情（04）；点 ⌃ 收起。
- 收起状态会记在这条消息上；刷新或重新进入对话后保持原样。

## 04 步骤详情（底部弹窗）
- 顶部：工具名、工作区、耗时，以及 exit 码徽章（0 为绿色，非 0 为红色）。
- 分段切换「命令 / 输出 / 错误」，内容用深色等宽代码区显示。
- 支持复制输出、在 Termux 中打开；长输出可以滚动，超过 64 KB 时截断并提示。
- 手势：下拉或点遮罩关闭。

## 05 任务完成
- 任务卡收成「✓ 已完成 6 步 · 用时」，仍可点开回看。
- 卡片下面是正式回答（Markdown），再下面是产出文件卡：缩略图、名称、页数和大小，配「打开」「分享」。
  - 「打开」调用系统 Intent，例如用 WPS 打开。
- 消息底部的操作：复制 / 重试 / 👍 / 👎。头像切成 happy，几秒后回到 idle。
- 出错时：卡片显示红色「第 n 步失败」，头像切成 error，并给出「重试这一步」「查看错误」。

## 06 敏感操作确认
- 触发条件：发送消息、发帖、支付、删除文件、安装应用、修改系统设置，或在密码框附近操作。
- 任务卡变成琥珀色「等待你确认 · 第 n/N 步」，同时弹出底部确认单：
  - 动作标题与对象，例如「在微信给『妈妈』发送消息」。
  - 将要输入或发送的内容预览，可以「编辑」。
  - 本步会发给模型的数据量（屏幕文字条数 / 截图张数）。
  - 「本对话内同类操作不再询问」复选框，默认不勾；支付和密码类没有这个选项。
  - 「取消」或「确认发送」。
- 密码、验证码、支付密码只能由用户亲手输入，Agent 不填写。
- App 在后台时，用高优先级通知加悬浮窗提示确认。

## 07 Hands 正在操作其他 App（悬浮层）
- 屏幕边缘出现珊瑚色发光描边，表示正在自动操作。
- 要点击的位置会出现脉冲圈，让用户看到它下一步点哪里。
- 顶部悬浮胶囊显示：小头像、当前动作、⏸ 暂停、✕ 停止。
  - 暂停后用户可以手动接管，再点继续。
  - 停止会立刻结束任务，并回到 Clawdy。
- 底部小提示显示第几步。
- 用户手动触摸屏幕时自动暂停 3 秒，防止抢操作。

## 08 侧边栏
- 搜索对话、+ 新对话。
- 入口：工作区文件（14）、定时任务、记忆。
- 「最近」对话列表：当前对话高亮；长按可以重命名、置顶或删除。
- 底部：用户头像和名字，⚙ 设置（15）。

## 09 模型选择（底部弹窗）
- 按服务商分组列出已配置的模型，带能力标签（工具调用 / 识图 / 推理）；当前模型显示 ✓。
- 「深度思考」开关：只在支持推理的模型上可用。
- 「+ 添加服务商」进入 10。
- 切换只影响当前对话；默认模型在设置里改。

## 10 添加服务商（BYOK）
- 类型选择：DeepSeek / OpenRouter / OpenAI 兼容 / Anthropic 兼容。选了类型会自动填好 Base URL。
- 填写名称、Base URL、API Key（掩码显示，可点眼睛查看）和默认模型。
  - 默认模型下拉框会先拉 /models 列表，拉不到就手填。
- 「测试连接」：发一个最小请求，返回延迟，并检测是否支持工具调用。
  - 失败时显示具体原因（401 / 网络 / 证书）。
- Key 用 Android Keystore 加密后只存在本机，请求直接发给服务商，不经过任何中转。

## 11 工具连接
- 四张状态卡：
  - Termux：显示已连接，以及 Python / Node / Chromium 版本；可以重新运行初始化脚本。
  - Hands 无障碍：显示是否开启；未开启时跳到系统无障碍设置。
  - Linux 沙箱（Alpine）：显示是否就绪和占用空间；可以重置。
  - Shizuku：可选；未连接时显示「去连接」。
- 权限区：悬浮窗、通知、后台运行不受限制（电池优化白名单）的开关；点开关跳到对应的系统页面。
- 每次回到这一页都重新检测一遍状态。

## 12 首次引导（4 步）
1. 欢迎，选择昵称和语言。
2. 连接 Termux：检测是否已安装 → 复制 `allow-external-apps` 命令 → 授予 RUN_COMMAND 权限。每一项完成后自动打勾。
3. 开启 Hands 无障碍和悬浮窗。
4. 添加第一个服务商（10）。
- 任何一步都可以「稍后再说」，之后在工具连接（11）里补上。

## 13 附件面板
- 最近照片横向滚动。
- 六个入口：拍照、相册、文件、当前屏幕（截图并读取节点）、工作区文件、网页链接。
- 开关：联网搜索、Hands 操作手机（关掉后本条消息只能用 Termux 和对话）。
- 选中的附件以小胶囊显示在输入框里，点 ✕ 移除。

## 14 工作区
- 在 Termux（`~/clawdy/<任务名>`）和 Linux 沙箱之间切换。
- 面包屑导航，文件列表显示类型图标、大小和修改时间。
- 长按文件：分享 / 重命名 / 发给 Clawdy（作为附件开新对话）/ 删除（需要二次确认）。
- 右下角 + 新建文件夹或导入文件。

## 15 设置
- 顶部：Clawdy 头像和「人设与提示词」入口，可以编辑名字、性格和系统提示词。
- 模型：服务商与 API Key、默认模型。
- 安全：
  - 敏感操作确认：始终询问 / 本对话询问一次。
  - 截图上传：默认关，默认只把文字节点发给模型。
  - 不在密码框上操作：默认开。
- 工具：工具连接、运行日志（每次工具调用的完整记录，可导出）。
- 外观：主题跟随系统 / 浅色 / 深色。
- 关于：版本、GPL-3.0 开源许可、第三方许可。

## 主流程串联
首页(01) →发送→ 任务卡收起(02) ⇄ 展开(03) → 步骤详情(04)
                      ↓ 遇到敏感操作 → 确认单(06) → 继续
                      ↓ 需要操作其他 App → Hands 悬浮层(07) → 回到 Clawdy
                      ↓ 结束 → 完成与文件卡(05) → 工作区(14)
首次启动 → 引导(12) → 服务商(10) → 首页(01)
